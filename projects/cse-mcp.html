PROJECT OVERVIEW

Connecting AI With Market Data

The project creates a bridge between AI assistants and Colombo Stock Exchange market information. Instead of manually searching for share data, an AI client can call a dedicated MCP tool and receive structured stock information.

Stock Quote Lookup

Retrieve share price, daily change, percentage movement and company information using a CSE symbol.

AI Integration

Makes market information available as a structured tool that compatible AI assistants can call directly.

MCP Server

Uses the Model Context Protocol to expose market functionality through a clean and reusable interface.

Remote Access

The MCP server can be accessed remotely so an AI client can use the tool beyond the local computer.

SYSTEM ARCHITECTURE

How It Works

A simple architecture keeps the AI client separate from the market-data layer while the MCP server handles the communication between them.
User Requests stock information
AI Client Calls the MCP tool
CSE MCP Server Retrieves and structures market data
